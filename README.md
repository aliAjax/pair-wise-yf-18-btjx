# 珠宝镶嵌宝石分拣台

面向珠宝镶嵌工作室的纯前端裸石分拣系统，替代纸卡登记，避免批次收尾时把尺寸不合或缺检的宝石带进订单。

## 功能

- **裸石登记**：编号、种类、形状、克拉、尺寸（长×宽 mm）、净度、颜色、切工、缺陷说明；每颗先归入分拣批次
- **分拣批次**：新建 / 切换 / 封存；封存后该批记录全部只读
- **订单分配**：主石位只放 1 颗，围石位最多 8 颗（按 1–8 编号占用）；已属其他订单的宝石不能再次分配
- **位置示意图**：主石居心、围石环绕的镶嵌位盘，点击位置查看详情、放入或移出
- **尺寸筛选**：按形状、长边 mm 区间、编号/种类/颜色关键字筛选，可只看待分配
- **订单清单**：主石位、八位围石、合计克拉与完整资料，与分拣台、位置示意共用同一份记录
- **封存判定**：封存前检查未处理缺陷与位置超额；有冲突则逐条列出并保留原分配，封存失败
- **本地存档**：所有数据存于浏览器 localStorage，关闭浏览器再打开待办仍在；无后端、无新增依赖

## 文件结构（三个业务文件）

| 文件 | 职责 |
| --- | --- |
| `src/judge.ts` | 判定：领域类型、登记校验、分配规则、封存冲突、尺寸筛选（纯函数） |
| `src/store.ts` | 存档：localStorage 持久化、种子数据、全部读写动作（`useSortingStore`） |
| `src/pages.tsx` | 页面：分拣台、镶嵌位置、订单清单三个业务视图 |
| `src/App.tsx` | 页签、顶部指标与操作提示 |
